【 一、这个补丁干什么 】
--------------------------------------------------------------------------------
开新档的那一刻，你会直接拿到：

    · 持有 380 円                        （不用再从头攒钱）
    · 99 个「市村可乐饼」                （RPG Maker MV 单格上限）
    · 无限模式：可乐饼数量永远不会少于 99 个
    · 开局自动收集【全部线索】           （所有「线索：xxx」道具，省去回头搜刮）
    · 开局自动发放【北巷七件套】         （四张碎纸片 + 三件乱码饮料，破解鬼打墙）
    · 开局自动弹 7 页版权声明            （一条一页，按确定键逐页跳过即可）

以上全部已在真机上验证过（Steam 正版 + nw.exe 开新档）：

    2026-10-09  v2.4.0   开局 380 円 + 99 可乐饼 .................... 通过
    2026-10-10  v2.5.0   380 円 / 可乐饼 x99 / 碎纸片 A~D /
                         三件乱码饮料 / 线索页 28 件全收 ........... 全部命中

    进图后顶部会显示「长野七号商业街 · 持有 380 円」，
    打开「道具 -> 物品」应看到：市村可乐饼 :99、碎纸片 A/B/C/D 各 :1、
    三件乱码饮料各 :1；切到「线索」页应有 28 条「线索：xxx」。
    看不到就是装错了或读的老档（见第六节）。

不修改存档文件、不注入进程、不改内存，纯粹是游戏自己的脚本层扩展，
所以背包上限、物品日志、成就、云存档全部照常工作。


【 二、怎么用 】—— 三步，一分钟
--------------------------------------------------------------------------------
  1. 把整个文件夹解压到任意位置（路径别带中文更保险）。

  2. 双击 install.bat

     脚本会自动扫描你的 Steam 库，找到「买个可乐饼吧！」并安装。
     装完会显示一段绿色的成功信息，按任意键关闭。

  3. 启动游戏，开一个新档。

     如果游戏是用 nw.exe 直接跑的，就用 nw.exe 启动；
     （Game.exe 是 RPG Maker 的引擎本体，双击它不会启动游戏）

  找不到游戏？手动指定路径：

      install.bat -GamePath "I:\SteamLibrary\steamapps\common\Buy a Croquette"

  安装前的其他说明：
      · 装之前请先关闭游戏，否则改动下次启动才生效
      · 补丁只对【新档】生效，读老档不会追溯补给

【 四、想改数值？ 】
--------------------------------------------------------------------------------
安装后打开游戏目录下的：

    www\js\plugins.js

找到 KC_InfiniteCroquette 这一项，改里面的 parameters 就行，不用动代码：

    "parameters": {
        "Starting Gold":     "380",        <- 开局金钱
        "Croquette Item ID": "2",          <- 物品 ID，一般不用改
        "Croquette Amount":  "99",         <- 开局数量 / 无限模式的保底数量
        "Infinite Mode":     "always",     <- 无限模式，见下
        "Collect All Clues": "true",       <- 开局自动收集所有「线索」道具
        "Extra Item IDs":    "11,12,13,14,15,16,17",  <- 额外发放的物品 ID（逗号分隔，各 1 个）
        "Notice Face":       "qianxu4",    <- 开局声明框的立绘，填 none 就不显示
        "Notice Face Index": "0"           <- 立绘表情编号（0 开始）
    }

Collect All Clues / Extra Item IDs（开局收集）：

    Collect All Clues = true  时，开局自动把名称以「线索」开头的道具全发给你
    （游戏里一共 28 件，如「线索:午夜之声」「线索:达摩眼睛A」等）。
    设为 false 则只按 Extra Item IDs 发。

    Extra Item IDs 默认 "11,12,13,14,15,16,17"，正好是北巷鬼打墙所需的七件：
        11/12/13/14  四张碎纸片（写明破解步骤）
        15/16/17     三件乱码饮料：2 円瓶装 / 5 円盒装 / 3 円杯装
    （乱码店名是游戏刻意的演出效果，不是乱码错误）

    这两项只往背包里塞普通道具，不碰任何开关或变量，剧情推进依旧由游戏自己判定。

Infinite Mode 的三个取值：

    always   任何途径让数量掉下去都会立刻补满（默认，真·无限）
    consume  只在你「使用」可乐饼后补满；卖店/丢弃会正常减少
    off      关闭无限，只在开局发一次 99 个

    提示：always 模式下在商店卖可乐饼也不会减少，等于无限刷钱。
          如果你不想让经济系统崩掉，改成 consume 就好。

关于开局声明框：

    开场「知道了……」这句对白结束后、任务目标横幅弹出来之前，
    会自动插进 7 页版权声明。一条一页，按确定键一页一页跳过就行，
    和游戏原本的对白一模一样（长按加速、鼠标、手柄都照常）。

    想改文案：编辑 plugin\KC_InfiniteCroquette.js 顶部的 NOTICE_LINES 数组。
    想换立绘：改上面的 Notice Face（填 none 则不带立绘）。


【 五、怎么卸载 】
--------------------------------------------------------------------------------
双击 uninstall.bat 即可。

它会：
    · 从 plugins.js 里摘掉插件条目（其他插件原样不动）
    · 删除插件文件
    · 保留 _cheat_backup_时间戳 备份目录

想连存档一起还原（从安装时的备份覆盖）：

    uninstall.bat -RestoreSave

    警告：这一步会覆盖你现在的存档，是在还原到你安装补丁之前的状态。


【 六、常见问题 】
--------------------------------------------------------------------------------
Q: 装完进游戏一看，还是 0 円？
A: 三个可能：
   1) 你读的是老档 —— 补丁只对新档生效，请开新游戏。
   2) 游戏在安装前就已经开着 —— 关掉重开。
   3) 你运行的游戏不在安装时选中的目录里。

Q: 会不会被封号 / 被云存档检测到？
A: 不会。补丁不碰内存、不注入进程、不联网，只是往游戏自带的 JS 里加了一个文件，
   行为上跟装一个普通插件完全一样。

Q: 会不会影响成就？
A: 不会。物品是通过引擎标准接口 gainItem 发放的，等同于你自己捡到 99 个。

Q: 我改了参数没生效？
A: 改完要重启游戏。而且补丁只作用于新档。

Q: 卸载后游戏打不开 / 报错？
A: uninstall.bat 已经自动做了语法校验，失败会自己从备份还原。
   还是不行的话，手动把 _cheat_backup_xxx\plugins.js.bak 复制回 www\js\plugins.js。


【 七、技术实现（给爱看代码的人） 】
--------------------------------------------------------------------------------
1. 注入点选在 DataManager.setupNewGame —— 只在新游戏触发，读档完全不沾。

2. 本作启用了 jumpbegin.js，标题画面被跳过，启动即自动进地图；
   因此注入同时挂在 Scene_Map.start 上做兜底，两条启动链都能命中。

3. 本作启用了 ParallelParty.js，参数 ShareResource = OFF（队伍资源不共享）。
   开场剧情会执行 $gameParty = currentParty，把整个队伍对象换掉 ——
   刚发下去的钱和物品会跟着旧对象一起消失，表现为「瞬间归零」。
   补丁会监测 $gameParty 的对象身份，首次被替换后补齐一次，然后停止监测。

4. 全程只用引擎标准 API（gainItem / gainGold / loseItem），
   不直接篡改内部字段，因此不影响任何依赖这些接口的既有机制。

5. 开局声明框走的是「运行时指令注入」：Show Text（指令 101）会吃掉它后面
   所有 401 文本行，硬塞 7 行只会挤在同一页。所以补丁在解释器执行到插入点
   时，把 7 组 101+401 指令就地 splice 进指令表，剩下的交给引擎自己跑 ——
   翻页、等待、跳过、长按加速全部是原生行为。
   只在内存生效，不落盘、不改任何 Map*.json。
